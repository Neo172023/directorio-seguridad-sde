# Directorio de Seguridad y Emergencias — Santiago del Estero

Aplicación ciudadana independiente, no oficial.

## Publicar

En GitHub: Settings → Pages → Deploy from a branch → main → / (root) → Save.

## Datos

El archivo datos.json procede del PDF aportado por el usuario, fechado 28/10/2025. Los teléfonos no están comprobados de forma independiente. Revisar números dudosos antes de usarlos en emergencias. El buscador permite filtrar por departamental y nombre, con llamadas y búsquedas en mapas.

## Limitaciones

Primera versión estática sin panel administrativo ni verificación automática de teléfonos. Maps realiza búsquedas textuales, no geolocalización validada.
